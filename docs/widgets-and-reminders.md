# Annum Widgets and Reminders

Annum can support reminders and home-screen widget workflows depending on the current version and device.

## Reminder guidance

- Review reminder dates and times before relying on them.
- Confirm Android notification permissions are enabled where required.
- Device battery or background restrictions can affect reminder delivery.

## Widget guidance

- Re-add the widget after major launcher or device changes if needed.
- Confirm Annum is still installed and available to the launcher.

## About this documentation

This document covers public, user-facing behavior only.

It does not publish internal reminder logic, notification implementation details or private app architecture.
